# 角色学习卡片网页升级包

这个包只包含一个文件：

- vocab_cards.html

它会把你的词汇网页升级成“带人物的学习卡片”样式。

## 使用方法

把这个 `vocab_cards.html` 复制到你的项目根目录：

A:\Git\project\Oxford3000-RPG\vocab_cards.html

覆盖原来的 `vocab_cards.html`。

然后启动服务器：

python -m http.server 8000

浏览器打开：

http://localhost:8000/vocab_cards.html

## 注意

这个版本不会覆盖 characters、story、index.html，也不会动你的世界观。
